A local, read-only support retrieval service. It returns an exact policy excerpt with a citation, or abstains. No invented answers, no account actions, no paid model keys. AI-assisted demo using fictional shop policies.

What actually happens

  1. 01 Validate input and check a small pattern guard
  2. 02 Route account actions to a secure human path
  3. 03 Rank 10 documents with TF-IDF + cosine similarity
  4. 04 Apply a score and ambiguity threshold
  5. 05 Return the exact excerpt and policy reference

This is an extractive retrieval baseline, not a generative LLM or a claim of production security. The guard is illustrative and can be bypassed. Scores are lexical similarity, not calibrated confidence.

Evaluation uses manually authored English cases and fictional policy documents. It is a small regression set, not proof of real-world accuracy. No questions are stored by this application. Deploy behind authentication, request limits, monitoring and security review before any real use.
